# VITALINK 360 — Paquete visual conceptual

Subí el contenido de la carpeta `assets/` a la carpeta `assets/` de la raíz del repositorio `InstructorMap/vitalink360`.

Los archivos WebP son recortes del tablero visual original, no iconos vectoriales independientes. Los botones de servicios incluyen texto integrado en la imagen: para accesibilidad y responsive conviene usar las imágenes como referencia y mantener botones HTML reales.

**Importante:** las escenas con ambulancia, helicóptero, edificio y central son ilustraciones generadas por IA, no fotografías de recursos o instalaciones existentes. No usarlas para afirmar disponibilidad de medios reales. Revisar tipografías y rotulación generadas antes de publicar comercialmente.

Archivos: brand-banner.webp, app-icon.webp, hero-rescate.webp, service-buttons.webp, centro-medico.webp, ambulancia.webp, helicoptero.webp, central-operativa.webp, iconography-palette.webp, ecg-background.webp, wave-background.webp, medical-tech-background.webp.

El archivo `brand-board.jpg` es la referencia general de estilo.
