Ejemplo de flujo (sin datos reales)

  1. El socio solicita asistencia.
  2. La API registra la solicitud de forma idempotente.
  3. La central confirma recepción y emite un identificador.
  4. Un operador evalúa y asigna recursos.
  5. El socio ve estados confirmados.

Este panel no ejecuta ninguno de estos pasos todavía.
